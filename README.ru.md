# earshot

Запись созвонов для GNOME на Wayland, о которой не надо помнить. Когда приложение созвона занимает
микрофон, earshot спрашивает, записывать ли. Вскоре после созвона в вебе готова страница: саммари,
action items, транскрипт со спикерами и плеером, ссылка, чтобы поделиться. По архиву можно искать в
вебе и из Claude через MCP.

[English version](README.md)

## Статус

Ранняя разработка. В репозитории есть ТЗ, решения, правила и каркасы демона и сервера; записывать
пока нечему. Следующий шаг — этап 0: замеры распознавания речи и настроек видео на реальном железе.
См. [docs/roadmap.md](docs/roadmap.md).

## Как это работает

- **earshot-daemon** (Rust) следит за PipeWire. Когда приложение вроде Telegram Desktop, Zoom,
  Discord, Slack или браузера держит микрофон, он спрашивает через расширение GNOME. При «да» пишет
  две дорожки — твой микрофон и всех остальных — и монитор с окном созвона.
- **Расширение GNOME Shell** показывает вопрос, индикатор в панели и Quick Settings. Само оно ничего
  не записывает: падение gnome-shell запись не останавливает.
- **earshot-server** (Python) транскрибирует созвон кусками прямо по ходу, разделяет спикеров и
  пишет саммари локальной или настроенной языковой моделью. Работает на твоём ПК или на небольшом
  VPS, раздаёт веб и MCP.

Подробности: [docs/spec.md](docs/spec.md), [docs/architecture.md](docs/architecture.md) (на
английском).

## Требования (целевые)

GNOME Shell 45–51 на Wayland, PipeWire, видеокарта NVIDIA для локального распознавания на ПК (на
VPS хватает CPU), gpu-screen-recorder для видео.

## Запись других людей

Законы о записи разговоров разные: где-то нужно согласие всех участников. earshot спрашивает перед
каждой записью и напоминает предупредить собеседников; предупредить их — твоя ответственность.

## Репозиторий

| Путь | Что |
|---|---|
| `daemon/` | демон на Rust |
| `server/` | сервер на Python |
| `tools/checks/` | проверки репозитория |
| `docs/` | ТЗ, решения, архитектура, контракт, этапы |
| `plugins/bedrock/` | встроенный плагин [bedrock](https://github.com/paranoica/bedrock) для Claude Code, на котором ведётся разработка earshot; с ним правила работы в репозитории действуют без установки |

## Разработка

```
cargo test --workspace                       # демон
uv run --directory server pytest             # сервер
(cd tools/checks && uvx pytest@9.1.1)        # проверки репозитория
git config core.hooksPath .githooks          # проверки перед коммитом
```

Правила работы для людей и агентов: [AGENTS.md](AGENTS.md). Сообщить об уязвимости:
